# KJ 光榮獅正面比例矩陣 v0.1

> 來源：Vincent 提供的附件正面圖，作為全身比例 master。這份矩陣先用於標線／疊圖確認；未經確認前，不取代正式角色規格。

## 1. 基準定義

- `H`：附件中鬃毛最高點至腳底基準線的垂直高度。
- `C`：角色身體中心軸；正面胸章與左右腳配置以 `C` 對稱。
- 所有局部重建必須鎖定 `H`、`C` 與腳底基準線；不得讓生成模型重新決定腿長。

## 2. 附件 anchor（目前標線版）

| Anchor | 相對於 H 的位置 | 用途 |
| --- | ---: | --- |
| 鬃毛最高點 `Y0` | 0.000 | 全身上界 |
| 眼線 | 0.336 | 頭部高度與眼睛位置 |
| 下巴／頸線 | 0.542 | 頭部與披風交界 |
| 披風肩線 | 0.534 | 披風起點，不得上移到臉部 |
| 胸章上緣 | 0.527 | 胸章框起點 |
| 胸章下緣 | 0.798 | 胸章框終點 |
| 腹部／髖部線 | 0.823 | 軀幹與腿部交界 |
| 腳掌上緣 | 0.848 | 可見腿段上界 |
| 腳底基準線 | 1.000 | 全身落地基準 |

## 3. 寬度與框體

- 頭／鬃毛框：寬約 `0.693H`，高度約 `0.581H`。
- 軀幹框：寬約 `0.484H`，由 `0.524H` 延伸至 `0.852H`。
- 胸章框：寬約 `0.231H`、高約 `0.274H`；正面盾形比例固定。
- 披風包絡：寬約 `0.823H`，由 `0.524H` 延伸至約 `0.913H`。
- 雙腳包絡：寬約 `0.458H`；腳底必須同時落在 `Y=1.000H`。
- 尾巴根部：相對中心軸向角色右側約 `0.116H`，垂直位置約 `0.823H`。

## 4. 硬性驗收規則

1. 腳底基準線固定；任一腳不得因生成而下移或拉長。
2. `0.823H` 腹部／髖部線至 `1.000H` 腳底線是短腿區，不得增加長腿段。
3. 頭／鬃毛框、軀幹框與胸章框須同時落在標線內；任一框體漂移即退回重做。
4. 披風只能依附件包絡重建；其邊界不能改變腿長或尾巴根部位置。
5. 尾巴、胸章、鬃毛與披風是附屬結構，不能反過來拉伸身體骨架。
6. 先通過比例疊圖，再進行局部造型與材質轉換；未通過前不更新六面總表。
