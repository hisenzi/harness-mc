Routing

首頁與下層分工
首頁
只保留是否要管、先管哪裡、資料新不新、需要誰批准。
專案頁
放完整 task list、track、order label、done condition、依賴與狀態歷史。
Pipeline
放 reducer、pending event、sync event、error detail 與 replay evidence。
Worktree
放 dirty file、commit grouping、4C gate 與 push/deploy 邊界。

Boundary

首頁不可做的事
Dashboard 是 read-only。它可以顯示、排序、連到下層頁，但不可關閉 task、不可 commit、不可 push / deploy、不可對 Heptabase 或 Canvas 反向寫入。
設計原則：sidebar 承擔分類與分流，首頁承擔判斷。資訊多時不要在第一屏展開所有細節；只保留全域狀態、最優先 open loop、需要 Vincent 決策的 queue，以及資料新鮮度。
