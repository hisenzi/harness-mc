# KJ 光榮獅正面比例矩陣 v0.2

> 來源：Vincent 提供的附件正面圖。v0.1 將腹部／髖部線抓得過高，造成生成稿腿段過長；本版以下半身實際像素位置重新校正。

## 1. 基準

- `H` = 鬃毛最高點至附件實際腳底線。
- 目前量測基準：`Y0 ≈ 133 px`、`foot baseline ≈ 1607 px`、`H ≈ 1474 px`。
- 腳長驗收以附件像素位置為準，不以「短腿」文字描述代替。

## 2. 校正後 anchor

| Anchor | 附件像素 y | 相對於 H | 用途 |
| --- | ---: | ---: | --- |
| 鬃毛最高點 `Y0` | 133 | 0.000 | 全身上界 |
| 眼線 | 602 | 0.318 | 頭部比例 |
| 下巴／頸線 | 878 | 0.505 | 頭部與披風交界 |
| 披風肩線 | 872 | 0.501 | 披風起點 |
| 胸章上緣 | 850 | 0.487 | 胸章框起點 |
| 胸章下緣 | 1235 | 0.747 | 胸章框終點 |
| 身體下緣／髖部 | 1357 | 0.830 | 短腿段起點 |
| 腳掌上緣 | 1460 | 0.900 | 腳掌段起點 |
| 腳底基準線 | 1607 | 1.000 | 全身落地基準 |

## 3. 腳長硬規則

- `0.830H → 1.000H` 是附件下半身總高度；生成稿不得把身體／腿部起點提前到 `0.75H` 左右。
- `0.900H → 1.000H` 是腳掌主要可見區；腿部不可出現細長小腿。
- 雙腳必須同時落在同一條 `Y=1.000H` 基準線；腳掌寬度與附件相近，不以細長比例替代。
- 若生成結果的腹部／髖部低點高於 `0.830H`，或腳掌上緣高於 `0.900H`，直接判定 V07 不通過。

## 4. 其他框體

- 頭／鬃毛框：仍以附件外輪廓為主，約 `0.69H` 寬。
- 胸章框：上緣 `0.487H`、下緣 `0.747H`，盾形比例固定。
- 披風包絡：肩線約 `0.501H`，下緣不得改變腿部 anchor。
- 尾巴根部：約位於 `0.78–0.83H` 的身體右側後方；不可因尾巴造型拉高身體。
