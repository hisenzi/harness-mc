## 驗收項目

### A. 永久角色核心

- [ ] 金黃色幼獅、金藍鬃毛、深藍披風與親和比例成立。
- [ ] 正面胸章造型與比例固定，未因媒材轉換改變識別結構。
- [ ] 60 週年資訊只出現在應用層，不進入永久角色本體。

### B. 三視圖

- [ ] 正面：胸章、鬃毛、披風與尾巴的基準比例可讀。
- [ ] 側面：口鼻、胸腹、披風厚度、尾巴根部與尾飾連接合理。
- [ ] 背面：鬃毛後緣、披風背面、尾巴走向與封閉毛束完整。

### C. 細節簡化

- [ ] 鬃毛保留頂部上揚特徵；細碎毛束合併為大型金色與深藍色塊。
- [ ] 披風改為單層短披風，取消複雜皺褶與多層下襬，只保留一條金邊。
- [ ] 尾飾移除十字與火焰，改為厚實、封閉的金藍雙色毛束。
- [ ] 胸章正面造型固定；絨毛版為平面繡章／布章，PVC／軟膠版為一體成形浮雕。

### D. 色彩與材質適配

- [ ] 建立金黃色、深藍色、胸章藍與金邊的標準色表示方式。
- [ ] 2D 版本保留色塊、輪廓與胸章識別，不依賴細碎紋理。
- [ ] 絨毛玩偶版本定義布料、繡章／布章、填充與毛束的視覺轉換原則。
- [ ] PVC／軟膠版本定義一體成形浮雕、分色與厚度可行的造型原則。

### E. 使用邊界

- [ ] 可用規則可直接指導 2D、絨毛與 PVC／軟膠延伸。
- [ ] 不可用規則明確禁止破壞胸章比例、恢復複雜尾飾、混入 60 週年永久化元素等情況。
- [ ] 不包含工廠打版、3D 建模、開模、樣品打樣及正式量產。
